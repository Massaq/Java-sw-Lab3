## Опис проєкту
Сервіс аналітики безпекових логів `SecurityLogAnalyzer` у пакеті `ua.kpi.comsys.streams` для роботи з нескінченними потоками даних (`Stream<SecurityLog>`):
1. `findFirstCriticalEvent` — пошук першої події з рівнем `"CRITICAL"` за допомогою короткого замикання (`findFirst`) та безпечної роботи з `Optional`.
2. `getLogsBeforeDeadline` — вибірка подій із нескінченного потоку до вказаного дедлайну за допомогою `takeWhile`.
3. `detectIpBursts` — власний статевий (stateful) `Gatherer`, який відстежує неперервні серії запитів з однієї IP-адреси та фіксує атаку типу "Burst" при досягненні порогу `burstThreshold`, зупиняючи обробку після знаходження `maxIpsToReport` адрес.
